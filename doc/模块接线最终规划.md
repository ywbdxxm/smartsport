# ESP32-S3 模块接线最终规划

更新日期：2026-09-16

适用硬件：

- 芯路城 ESP32S3 开发板，模组 `ESP32-S3-WROOM-1-N16R8`
- `ESP32S3-BASE01A V1.0` 引脚扩展底板
- JYTech ICM-45686 纯传感器模块
- Waveshare Micro SD Storage Board（SKU 3947）
- Quectel LC29H (EA) 定位方案；载板型号和针脚仍待实物确认

## 结论与状态

- IMU 和 SD 卡的电源、信号及 GPIO 分配已经定版，可按本文接线。
- GNSS 的 UART、PPS 和 RESET 所用 GPIO 已定版，但供电、逻辑电平、RESET 极性和载板物理针脚尚未定版。在确认所购载板正反面照片或原理图前，不给 GNSS 上电。
- 所有模块必须与 ESP32 共地。插拔跳线前先断电。

## 底板插针规则

`ESP32S3-BASE01A V1.0` 每个 GPIO 对应四排彩色插针：

| 颜色/丝印 | 用途 |
| --- | --- |
| 黄色 `S` | 对应 GPIO 的 3.3 V 逻辑信号 |
| 红色 `5V` | 5 V 电源 |
| 黑色 `G` | 地 |
| 蓝色 `3.3V` | 3.3 V 电源 |

模块信号线只接黄色 `S`，不能接红色 `5V` 或蓝色 `3.3V` 电源排。电源线必须按各模块表格选择，不能因为插针位置相邻而混接。

## GPIO 总表

方向均以 ESP32 为参照。

| GPIO | 最终用途 | 方向 | 当前状态 |
| --- | --- | --- | --- |
| `GPIO7` | ICM-45686 `INT1` | 输入 | 已接线预留；当前固件仍使用轮询 |
| `GPIO8` | ICM-45686 I2C `SDA` | 双向 | 已使用 |
| `GPIO9` | ICM-45686 I2C `SCL` | 输出 | 已使用 |
| `GPIO10` | SD `CS` / `D3` | 输出 | SD SPI 预留 |
| `GPIO11` | SD `MOSI` / `CMD` | 输出 | SD SPI 预留 |
| `GPIO12` | SD `SCLK` / `CLK` | 输出 | SD SPI 预留 |
| `GPIO13` | SD `MISO` / `D0` | 输入 | SD SPI 预留 |
| `GPIO14` | SD `CD` 插卡检测 | 输入 | SD 插卡检测预留 |
| `GPIO15` | GNSS `RESET`/控制 | 输出 | 仅预留；名称和有效电平待载板确认 |
| `GPIO16` | GNSS `PPS` | 输入 | 仅预留 |
| `GPIO17` | UART TX -> GNSS RX | 输出 | 仅预留 |
| `GPIO18` | UART RX <- GNSS TX | 输入 | 仅预留 |
| `GPIO48` | 板载 WS2812B 状态灯 | 输出 | 板载占用 |

这组分配让 IMU、SD 和 GNSS 各自连续占用一段 GPIO，避免启动配置、原生 USB、下载串口、Octal PSRAM 和板载灯冲突。

## ICM-45686 接线

| ICM-45686 丝印 | 底板连接 | 说明 |
| --- | --- | --- |
| `VIN` | 任一红色 `5V` | 模块允许 3.3-12 V 输入，厂商快速上手推荐 5 V；模块内部稳压到 3.3 V |
| `GND` | 任一黑色 `G` | 共地 |
| `SDA/MOSI` | `GPIO8` 黄色 `S` | I2C SDA，3.3 V 逻辑 |
| `SCL/SCLK` | `GPIO9` 黄色 `S` | I2C SCL，3.3 V 逻辑 |
| `INT1` | `GPIO7` 黄色 `S` | 数据就绪中断预留，当前固件尚未启用 |
| `ASD`、`ASL`、`INT2`、`AD0/MISO`、`CS` | 不接 | 当前阶段不使用 |

模块原理图显示：`SDA/MOSI`、`SCL/SCLK` 各有 4.7 kΩ 上拉，`AD0/MISO` 和 `CS` 各有 10 kΩ 上拉。默认 I2C 地址为 `0x69`，固件也会回退探测 `0x68`；`WHO_AM_I` 应为 `0xE9`。当前固件配置为 ±4 g、±1000 dps、200 Hz，采样轮询周期 100 ms，串口样本日志节流为每 1 s 一条。

## Waveshare Micro SD Storage Board 接线

该板是直接引出 microSD 信号的 3.3 V 模块，原理图中没有稳压器或电平转换器。`3.3V` 和所有信号都只能使用 3.3 V，严禁接 5 V。

按板上丝印接线，不要仅凭连接器左右方向数针脚：

| 模块 P1 | SPI 功能 | 底板连接 | 说明 |
| --- | --- | --- | --- |
| 9 `3.3V` | 电源 | 任一蓝色 `3.3V` | 只能 3.3 V |
| 8 `GND` | 地 | 任一黑色 `G` | 共地 |
| 7 `D0` | MISO | `GPIO13` 黄色 `S` | SD -> ESP32 |
| 6 `CMD` | MOSI | `GPIO11` 黄色 `S` | ESP32 -> SD |
| 5 `CLK` | SCLK | `GPIO12` 黄色 `S` | SPI 时钟 |
| 4 `D3` | CS | `GPIO10` 黄色 `S` | 片选 |
| 3 `D2` | - | 不接 | SPI 模式不用 |
| 2 `D1` | - | 不接 | SPI 模式不用 |
| 1 `CD` | 插卡检测 | `GPIO14` 黄色 `S` | 模块带 10 kΩ 上拉；实际插卡电平在上板时记录 |

模块的 `D0`、`CMD`、`CLK`、`D3`、`D2`、`D1` 和 `CD` 均有 10 kΩ 上拉。跳线阶段 SPI 从 10 MHz 起测。固件不得在挂载失败时自动格式化卡；首次测试使用已备份、FAT 格式的测试卡。

## GNSS 接线预留

| ESP32 | 计划连接 | 说明 |
| --- | --- | --- |
| `GPIO17` TX | GNSS RX | UART 发送 |
| `GPIO18` RX | GNSS TX | UART 接收 |
| `GPIO16` | GNSS PPS | 秒脉冲输入 |
| `GPIO15` | GNSS RESET/控制 | 具体名称和有效电平待载板确认 |
| `GND` | GNSS GND | 必须共地，但暂不接电源 |

现有资料是 LC29H 系列产品简介，不是所购载板的原理图。简介中的裸模块 LC29H (EA) 供电范围为 3.1-3.6 V、典型 I/O 电压为 2.8 V，不能据此推断淘宝载板已经带稳压或电平转换。取得实物后必须先确认：载板完整型号、正反面丝印、供电入口、电平转换、天线供电、UART 针脚、PPS 针脚以及 RESET 极性。

## 保留和避开的 GPIO

| GPIO | 原因 |
| --- | --- |
| `GPIO0`、`GPIO3`、`GPIO45`、`GPIO46` | 启动配置/Strapping 功能，不分配给当前模块 |
| `GPIO19`、`GPIO20` | ESP32-S3 原生 USB D-/D+，保留 |
| `GPIO35`、`GPIO36`、`GPIO37` | N16R8 的 Octal PSRAM 相关管脚，不使用 |
| `GPIO43`、`GPIO44` | 开发板 CH340 下载和日志串口，不使用 |
| `GPIO48` | 板载 WS2812B 状态灯，继续由固件使用 |

## 上电检查顺序

1. 断电状态下逐根核对模块丝印、GPIO 号、信号排和电源排。
2. 先只接 IMU，确认 `0x69/0x68` 探测、`WHO_AM_I=0xE9` 和 1 s 节流日志。
3. 断电后接 SD，先确认模块供电确为 3.3 V，再插入已备份的测试卡。
4. 运行 SD 冒烟测试：检测卡、挂载、写入、同步关闭、读回校验和卸载；失败不能影响 IMU 继续运行。
5. GNSS 在载板资料确认前保持不接。

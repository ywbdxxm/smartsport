# ESP32-S3-DevKitC-1 资料来源与使用说明

下载日期：2026-09-14  
资料来源：Espressif Systems（乐鑫）官方站点  
项目 SDK：ESP-IDF 6.1  
项目目标芯片：ESP32-S3

## 当前硬件身份

- 已知：开发板名称为 `ESP32-S3-DevKitC-1`。
- 未知：开发板是初始版本还是 v1.1。
- 未知：金属屏蔽罩上的完整模组型号以及 Flash/PSRAM 容量，例如 `ESP32-S3-WROOM-1-N8R8`。
- 因为模组型号未确认，当前同时保留 WROOM-1/1U 和 WROOM-2 的资料；后续配置 Flash、PSRAM 和保留 GPIO 时必须先确认实物丝印。

# 智能运动背心数据采集与存储架构

更新日期：2026-09-16

## 产品目标

设备统一采集 IMU、GNSS 定位和心率数据，并按一次运动一个会话文件保存到 SD 卡。存储变慢、SD 卡缺失或写入失败时，传感器采集不能被长期阻塞；固件必须明确记录丢包和“未记录”状态。

当前硬件基线是 ESP32-S3-WROOM-1-N16R8、JYTech ICM-45686 和 Waveshare Micro SD Storage Board（SKU 3947）。GNSS 载板的电气信息、心率器件及其协议确认后，再分别实现对应驱动。模块接线、电源限制和 GPIO 分配见 [模块接线最终规划](模块接线最终规划.md)。

## 分层与唯一所有者

```text
IMU 任务 ─┐
GNSS 任务 ├─> 带时间戳的类型化记录 ─> 有界队列 ─> 单一记录任务 ─> storage_sd ─> SD 会话文件
心率任务 ─┘
```

- 各传感器驱动只负责设备通信和物理量转换，不直接打开文件。
- 各生产者任务使用单调时钟给样本打时间戳，并以非阻塞方式提交类型化记录。
- 单一记录任务是队列消费、会话状态、序列化缓冲区和文件句柄的唯一所有者。
- `storage_sd` 是 SPI2、SDSPI 设备和 FAT 挂载的唯一所有者，其他组件不能绕过它操作该总线或挂载点。

这个边界让 GNSS 和心率模块后续可以独立接入，而无需改动 SD 驱动。

## 队列与过载策略

首版记录队列规划为 512 条固定大小消息。按每条约 64 字节估算，占用约 32 KiB；在总输入 200 Hz 时可缓冲约 2.5 秒。

生产者提交时不等待。队列已满则丢弃新记录，并按 IMU、GNSS、心率分别累计丢包数。队列恢复后，记录任务写入健康记录，包含各源丢包数和队列最高水位。这样既保持已接收记录的顺序，也不会让 SD 卡延迟反向阻塞采样。

## 时间模型

每条记录始终携带 64 位单调时间，单位为微秒。它是数据排序和时长计算的唯一基础，不受校时影响。

GNSS 获得有效 UTC 后，额外写入“单调时间—UTC 映射记录”，其中包含定位时间有效性和质量。离线工具根据映射给其他传感器补充 UTC；GNSS 失锁或校时跳变不会改变原始样本顺序。

## 会话和数据格式

每次运动生成一个版本化二进制会话文件。文件头记录格式版本、固件/板卡身份、会话序号和传感器配置。每条记录的统一外壳包含：

- 格式版本和记录类型；
- 载荷长度；
- 会话内递增序号；
- 单调时间戳；
- 类型化载荷；
- 覆盖记录头和载荷的 CRC。

离线解析器遇到最后一条不完整或 CRC 错误记录时停止，因此异常断电不会让此前完整记录失去边界。设备端不直接写 CSV；后续提供主机工具校验会话文件并导出 CSV。

文件名不依赖开机时已有 UTC，而使用启动/会话序号。GNSS UTC 映射保存在文件内部。GNSS 载板和心率协议确认后，再定版它们的载荷字段与完整字节布局。

## SD 写入和故障行为

- FAT 固定挂载到 `/sdcard`，固件绝不在挂载失败时自动格式化卡。
- 记录任务批量顺序写入，并至少每 1 秒、会话结束和关键健康事件时执行同步。
- 掉电时最多丢失最新的未同步区间；此前完整记录仍可解析。
- 无卡、挂载失败、写入失败或卡被拔出时，采集继续运行，同时进入明确的“未记录”状态。
- SD 恢复策略和热插拔流程在完成实卡故障测试后定版，首版不假设 GPIO14 的插卡有效电平。

## 当前已实现的第一阶段

当前固件只实现独立 `storage_sd` 基础组件和启动冒烟测试：

1. SPI2 使用 GPIO10 CS、GPIO11 MOSI、GPIO12 SCLK、GPIO13 MISO，初始 10 MHz。
2. GPIO14 仅作为普通输入打印原始电平，不参与挂载判断。
3. 挂载后创建 `/sdcard/smartsport_sd_test.bin`，写入确定性的 32 KiB 数据。
4. 执行 `fflush()` 和 `fsync()`，关闭并重新打开，逐字节读回校验且确认文件长度。
5. 只删除该诊断文件，卸载 FAT 并释放 SPI2。
6. 任一步失败均记录原因，然后继续启动 IMU。

本阶段不持续保存运动数据。下一阶段在定位和心率硬件身份确认后，实现统一记录结构、512 条有界队列、单一记录任务和会话恢复测试。

## 验证边界

主机测试覆盖确定性写入数据的生成、非零偏移和损坏位置报告；ESP-IDF 6.1 构建覆盖 ESP32-S3 编译和链接。板子当前未连接，因此 SD 卡识别、实际 SPI 信号、GPIO14 极性、32 KiB 实卡读写、拔卡和掉电恢复仍必须在硬件上验证。构建成功不能替代这些物理测试。

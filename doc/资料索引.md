## 硬件资料

- `模块接线最终规划.md`：当前 ESP32-S3、ICM-45686、Waveshare SD 卡板和 GNSS 预留的统一接线基线；接线前优先查看此文件。
- `硬件资料/芯路城-ESP32S3-N16R8/`：当前芯路城 ESP32S3 开发板的厂商资料，包含原理图、引脚图、尺寸图、芯片数据手册和配套下载资源。当前板载 WS2812B 使用 GPIO48。
- `硬件资料/ESP32-S3-DevKitC-1/`：乐鑫官方参考开发板、芯片和模组资料。该目录中的 DevKitC-1 引脚定义不适用于当前芯路城开发板。
- `imu/ICM45686-Module/`：ICM-45686 模块硬件和示例代码，作为外部 Git 子模块保留；使用前需遵守其分级许可证。
- `esp32底板/`：`ESP32S3-BASE01A V1.0` 参数和插针图；不是电气原理图。
- `定位模块/`：LC29H 系列简介和采购链接。现有资料尚不能确定所购 GNSS 载板的供电和物理针脚。

## 收录约定

1. 优先保存芯片、模组和开发板厂商发布的原始资料。
2. 每组资料附来源、下载日期、适用型号和校验值。
3. 搜索结果、商品描述和二手整理只作为线索，不能代替数据手册或原理图。
4. 只收录项目实际用到的资料，避免把整个厂商资料库复制进项目。
5. 型号或硬件版本不确定时明确标记，确认后再选择相应资料，不能用相近型号代替。
